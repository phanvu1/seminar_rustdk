📖 Hướng Dẫn Cài Đặt Cho Từng Máy

🪟 Thiết lập trên Windows

1. Tải file Vynex_Enterprise_Windows_v2.0.zip và giải nén.
2. Chạy file run_vynex.bat để kích hoạt Client và Dashboard.
3. Đăng nhập bằng tài khoản doanh nghiệp được cấp, hoặc mở ứng dụng để nhận mã ID/OTP hỗ trợ kỹ thuật.

🐧 Thiết lập trên Ubuntu (Máy ảo)

1. Mở Terminal máy ảo Ubuntu (phím tắt Ctrl + Alt + T).
2. Bấm nút Copy Lệnh Terminal ở trên và dán (Paste) vào Terminal.
3. Ứng dụng tự động kết nối API 10.13.13.1 và khởi chạy giao diện Nhân viên.
